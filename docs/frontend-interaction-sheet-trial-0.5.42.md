## 实现

- 计划编辑与个性化计划生成共用自定义动作组件。RootPortal 置顶面板；PageMeta 在面板期间锁定背景滚动。触发按钮保持挂载，不主动调用 pageScrollTo，避免开关表单改变背景高度/位置。
- 固定标题、关闭入口及底部创建操作，中部 ScrollView。输入使用现有明确高度，禁用原生自动推页，按键盘高度给面板留出空间，并在面板内部定位输入项。用户第二组已反馈输入、键盘及草稿恢复通过。
- 仅 transform/opacity 过渡；开场参数 320ms，退场 220ms，240ms 后隐藏。没有逐帧 JS、持续循环动画或业务等待动效结束。切后台停止装饰并隐藏面板，保留内存草稿；离页卸载取消定时器与键盘监听。
- 关闭面板不写入，也不清空创建表单或未提交的分类选择；成功创建后仍按原路径添加到对应训练日，不确认计划 Proposal。失败保留输入，提交中阻止重复创建及关闭；分类保存沿用原有结果核对流程。
- 编辑器以实际候选签名和自定义动作草稿判断脏状态。原样打开不警告；改动后警告，恢复原值解除；保存提案失败保持，成功导航前解除。原有 Proposal、安全、所有权、冲突校验不变。
- 所有新增色值来自现有主题，主题变量替换前后全局颜色不变。没有新增运行依赖。
