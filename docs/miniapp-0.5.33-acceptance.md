## 发布边界

- 仅小程序从 0.5.32 升级为 0.5.33。后端继续使用 0.5.32，数据库继续使用 0026。

- 不新增模型调用、营养策略、跨重启草稿或历史分页。

## 已实现

1. 克数输入与数值分离，以固定基准换算。清空、未完成或越界输入阻止保存；自定义营养明确使用当前份量总量，显式零合法，空白不合法。历史数据未修改的精度保持不变。
2. 训练历史可打开服务端关联的调整提案，复用原详情和确认接口；返回后重新读取状态，读取失败保留旧记录。完成页说明找回路径。
3. Agent 首次进入、返回和手动恢复共用入口，提交与轮询按原请求合并；切后台暂停本地轮询，保留后台任务。切换会话需明确确认，迟到结果不能污染新会话。
4. 刷新令牌仅明确 401 才退出；网络错误、429、5xx 保留凭证和恢复信息。并发刷新只执行一次；不自动重试结果未知的业务写入。
5. 饮食页先显示今日摄入和餐次，按需展开编辑，自定义表单默认折叠。今日、历史、食品搜索错误独立；搜索忽略旧响应；取消或切换编辑对象使用页内草稿确认。
