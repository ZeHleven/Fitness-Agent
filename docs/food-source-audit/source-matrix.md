## 核验与原始证据

- JSON 保留每个选中样品的原名、原字段、原值、缺项、来源代码、可食部描述、版本或快照日期及来源链接；未知来源方法不被标为“实测”。

- JSON 保留4/4/9比较作为数据诊断，不当作更正依据；保留来源修约和理论零值标记。
