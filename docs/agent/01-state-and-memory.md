# 对话状态与长期记忆

## 状态分层

1. **请求状态**：本轮原始消息、解析后的意图、工具白名单、工具结果和安全决策；请求结束后写入审计记录。
2. **会话状态**：最近消息摘要、未完成意图、待澄清槽位和待确认提案；按会话隔离。
3. **长期记忆**：稳定偏好和经用户确认的事实，例如训练目标、可用器械、常用训练时间。业务真相仍以用户资料、健康筛查、训练计划和训练记录表为准。

## 写入原则

- 只保存对未来对话确有价值、来源明确的事实。
- 健康、疼痛、伤病等敏感信息不从闲聊中静默写入永久资料。
- 推断必须标注为推断，不能覆盖用户显式资料。
- 记忆写入属于写操作，第一版只生成候选记忆，不自动执行。
- 用户可查看、更正和删除长期记忆。

## 上下文优先级

当前用户明确输入 > 当前业务数据 > 已确认长期记忆 > 会话摘要 > 模型推断。发生冲突时保留来源并优先澄清，不自行合并成新事实。

## 当前实现状态

- 会话消息已持久化，并在每轮装配最近消息作为短期上下文。
- 意图路由会读取最近上下文处理省略和指代；明确的助手查询提议只允许由“需要”“好的”“继续”等白名单承接语继承，不能从任意历史内容扩大工具权限。
- 用户资料、健康筛查、训练计划和训练记录通过只读工具实时查询，它们是业务事实，不复制为对话记忆。
- `agent_memories` 表目前仍是长期记忆预留结构，尚未启用候选生成、用户确认、读取和删除闭环。
