# 阶段 3：结构化意图、评测与小程序对话

实施日期：2026-08-19。

## 已实现

### 结构化意图解析

- 使用独立的低温度 `ChatOpenAI` 意图模型，通过 DeepSeek Chat Completions 的 JSON 模式生成 `IntentResolution`。
- Pydantic 再校验主意图、拓展意图、子任务、缺失槽位、澄清、风险和置信度；模型不能新增意图或工具 ID。
- 结构化解析失败只修复一次；第二次失败回退确定性规则解析。
- `ToolRouter` 仍在模型外生成服务端白名单；必须澄清或命中健康红旗时不暴露任何工具。
- 胸痛、呼吸困难、晕厥、失去意识和严重急性疼痛使用确定性安全覆盖，并在主 Agent 循环前返回停止训练和及时就医提示。

### 可观测性

Alembic `0012` 为 `agent_runs` 增加：

- 意图来源、置信度、尝试次数和降级原因。
- 是否必须澄清。
- 整体耗时和主 Agent 输入/输出令牌数。

业务用户、计划和训练记录表没有改变。意图模型错误只记录稳定类别，不记录密钥或完整供应商响应。

### 离线评测

固定集位于 `backend/evals/agent_intent_cases.json`，当前覆盖一般问答、七种只读查询、复合意图、提示注入、写请求隐藏和健康红旗。

规则基线结果：

- 15 个样例。
- 主意图正确率 100%。
- 风险等级正确率 100%。
- 允许工具召回率 100%。
- 禁止工具泄漏率 0%。

真实 DeepSeek 固定集最终结果：

- 15/15 样例均由真实模型完成，无规则降级。
- 主意图正确率 100%。
- 风险等级正确率 100%。
- 允许工具召回率 100%。
- 禁止工具泄漏率 0%。

真实 HTTP Agent 闭环还验证了普通问答和 `workout.get_next` 工具调用。无活动计划时，模型依据工具结果明确说明无数据，没有编造计划，也没有声称执行写操作。该次工具运行意图一次解析成功，置信度 0.97，总耗时约 5.95 秒。

运行规则评测：

```powershell
.\.venv\Scripts\python.exe backend\scripts\evaluate_agent_intents.py --mode rules --strict
```

配置本地 `DEEPSEEK_API_KEY` 后运行真实模型评测：

```powershell
.\.venv\Scripts\python.exe backend\scripts\evaluate_agent_intents.py --mode model --strict
```

脚本在模型模式缺少密钥时直接失败，不会把规则结果伪装成真实模型结果。

### 微信小程序 Agent 页面

- 新增 `pages/agent/index`，从训练首页的“问问训练搭子”入口进入。
- 支持恢复最近会话、开始新会话、快捷问题、发送状态、错误提示和只读数据卡片。
- 卡片覆盖资料、健康筛查、当前计划、下一练、进行中训练、历史和进度。
- 阶段 3 最初使用同步 90 秒客户端超时；微信 `callContainer` 实际受 15 秒通道超时限制，该路径已由阶段 4 的异步运行协议替代。
- 页面明确展示“当前不会直接修改训练数据”，写工具仍未开放。
