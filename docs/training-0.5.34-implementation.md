# 0.5.34 训练闭环优化（本地实现完成，待 CI 与真机验收）

范围：本轮用户确认的八项训练需求；不修改模型路由、饮食或生产环境。

- 北京时间、周一至周日；同一计划族同一周的训练日只能完成一次。调整提案复制计划时继承计划族，独立新建计划开始新计划族。
- 完成按钮是用户明确结束本次训练，不等于完成所有预定组数；详情同时显示目标和实做。保留记录并提前结束不占用已完成日。
- 旧计划已删除的进行中训练提供“保留记录并结束”；新删除提案在存在进行中训练时拒绝确认，先处理训练，不删除已记录组数。
- 已归档计划可从列表删除（隐藏），不删除训练历史和提案审计。
- 共用只读训练详情；记录每组实际休息，计时结束需点击开始下一组；未知历史休息显示“未记录”，不拿保存间隔冒充休息。
- 历史八周图可下钻七天，指标与列表随所选周切换。
- 私人自定义动作：支持动作库中不存在的新计次动作；名称、方法、器械等校验，服务端验证所有权及已知健康冲突。未知安全性允许手动添加，仅附近小字说明，无弹窗或勾选。不自动作为系统推荐动作；时间/距离制记录不在现有计次输入中伪造。
- 默认计划名去掉“入门”；历史仅识别系统默认名称作展示转换，不更改提案指纹或用户自定义名称。

## 自定义动作边界

编辑计划和生成个性化计划均可创建私人动作，再加入当前草案。定义使用稳定 ID，不接受客户端指定所有者或冒充安全审核结果；用户之间不可互相引用。定义不可原地改名，历史训练保存名称快照。

安全信息不足时允许手动添加，在表单、计划动作附近显示以下小字，无额外弹窗或确认勾选：

> 本平台仅提供记录与计划管理，请自行核对动作方法、训练负荷及身体适用性；如有疑问，请咨询专业人士。

这段说明不是安全认证，也不替代已知健康冲突拦截。当前沿用现有健康兼容规则，不声称能识别所有自由文本动作风险。不将未验证的私人动作自动加入系统推荐。当前支持计次训练，不新增按时长、距离记录的输入模型。

## 下一步验收清单

先经授权提交、推送并运行标准 CI，再使用匹配的测试后端与小程序做真机验收；合并后从干净 `main` 重新构建正式产物。部署及上传仍由用户控制。

1. 用测试计划完成一天：按钮变为“已完成”，再次点击进入详情，不能重复开始；逐天完成后显示“本周计划已完成”。跨周自动恢复新的完成进度。
2. 实际休息提前结束：例如目标 90 秒、约 17 秒时点击开始下一组，详情显示实际时间而非目标时间；切后台后返回仍连续计时。断网重试不得覆盖第一次结束时间。
3. 查看训练历史和详情：动作名称、各组次数/重量、实际休息一致；旧数据未知休息显示“未记录”。查看详情本身不得修改记录。
4. 点击八周柱状图的一周：显示七天、对应指标和对应训练记录；返回近八周恢复汇总，快速连续切换不得混入旧响应。
5. 孤立或旧计划的进行中训练：选择“保留记录并结束”后记录仍可看，新计划可以开始。此操作不冒充计划日已完成。
6. 归档计划列表删除：有页内说明，列表简洁，训练历史和提案仍可找回；活动计划仍走原有删除 Proposal。
7. 编辑器和个性化计划各创建一个库中不存在的私人动作：未知安全性只有小字，已知冲突不添加；编辑草案仍需要确认提案才能修改活动计划。
8. 系统计划标题不再出现“入门”；自行命名的历史计划不被擅自重写。检查长名称、小字、键盘遮挡和按钮易用性。
