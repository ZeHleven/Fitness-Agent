## 五、暂缓候选，不计入 66 项

- 红烧肉、宫保鸡丁、炒饭、盖浇饭、火锅等配方波动较大的菜品。
- 奶茶、咖啡调制饮品、外卖套餐。
- 大量品牌面包、蛋白粉、蛋白棒、零食；有明确包装营养标签时继续使用私人食品。
- “一碗／一份／一杯”通用估重、扫码和拍照识别，不纳入本轮。
- 首批食品的所有生熟组合不一次铺满；后续按用户称重习惯和来源可用性补充。

## 六、清单确认后的工作

1. 用户删减／补充食品，并决定生重记录与熟重直接记录的覆盖优先级。
2. 对每个保留条目核对精确来源、食品编号、版本、可食部、生熟／加工状态，以及热量、蛋白质、碳水、脂肪的完整同源数据。缺项不当作零，生熟不猜换算，4/4/9 不强制改写来源热量。
3. 只有来源匹配且可复用的候选进入确定清单；找不到可靠来源的条目暂缓。此文件未声称 66 项全部可获得合适数据。
4. 再做必要的分类／搜索独立预览，确认后实施到隔离版本。保留公共分类对 Agent 的兼容性和私人食品隔离，不改正式环境。
