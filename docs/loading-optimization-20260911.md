## 实现约束

1. 首页独立 GET 并行发起；仍等待个人资料引导状态校验后显示新结果。
2. 缓存为本次登录的内存快照，不持久化个人资料或业务数据；30 秒内复用，最多 40 项。新页面可先显示最近 5 分钟内的同日快照并立即刷新；已经显示的内容在失败时保留并提示重试。
3. 同键同代次的进行中读取合并。页面读缓存是显式选择，不缓存所有 API。编辑器、提案详情、执行结果核对及训练操作仍读取原 API。
4. 所有鉴权写操作在开始及结束时清空概览缓存，包括失败/响应不确定的写操作；不新增自动重试写入。Agent 异步运行终态清空概览，覆盖对话中确认提案的路径，不改意图或授权规则。
5. 登录、退出清空缓存并拒绝旧账号未返回的请求结果。正常 token 续期不视为换账号。
6. 北京时间日期变化后，下次进入或刷新重新读取；跨日期未返回的旧请求不能缓存成今天。今日饮食先清除昨日概览，餐次草稿的日期和内容不变。持续停留页面不做定时轮询。
7. 刷新保留已有内容、输入、草稿和展开状态；失败可重试。页面隐藏/卸载不再更新展示，隐藏时移除波光字符。
8. 首次读取显示深绿/橄榄色文字波光；已有内容时使用右侧小字号更新状态。波光 1.7 秒一轮；仅视觉显现延迟 120ms 避免快速读取闪烁，不设置最低等待时长，不延迟业务结果。完成和失败均停止。

## 证据

### 受控代码路径基线

`miniapp/scripts/benchmark-loading.mjs` 对正式基线与实现的真实 TSX 读取处理器，注入每请求 200ms 延迟，三次取中位数。React/原生宿主与 I/O 由测试运行器替代，不代表手机渲染或公网速度。

- 训练首页首次读取处理：约 416ms → 210ms，减少串行等待。
- 其他页面独立首次仍分别需要原有 2、2、2、1 个请求，没有宣称普遍首次提速。
- 五类页面短时间再次显示，读取请求均为 0；有写入、超时、换日或手动刷新后重新读取。

### 实际 H5 + 隔离 HTTP 对照

`scripts/qa-loading-browser.mjs live` 使用一次性 Edge 浏览器上下文，分别加载正式基线和优化版的真实 Taro H5，三轮相同流程。编译的本地 QA API 地址由浏览器路由适配到已验证 `test_id=agent-acceptance-20260910` 的局域网隔离后端；不是生产云托管或微信原生测速。

只登录既有合成账号并发送白名单 GET，无训练、饮食或提案写入；未调用模型。三轮结果均确认：

| 再次进入 | 基线读取次数 | 优化后读取次数 |
| --- | ---: | ---: |
| 训练 | 4 | 0 |
| 饮食 | 2 | 0 |
| 我的 | 2 | 0 |
| 历史 | 2 | 0 |
| 本次训练 | 1 | 0 |

顺序访问时，“我的”复用 profile，历史复用 progress，首次额外读取各降为 1。H5 导航受浏览器自动等待、页面切换和 DOM 可见性影响，耗时存在波动；尤其历史页不据此声称所有导航都更快。手机感受、原生动画及断网恢复的用户验收结果见下文，不将 H5 数值当作手机实测耗时。

2. 30 秒内来回进入相同页面：不应重复遮住内容；尤其“我的”与相同本次训练详情。30 秒后返回允许轻量更新，但不整页清空。
3. 在隔离账号修改今日餐次份量及个人资料，保存后返回关联概览：看到新数据而非旧缓存；恢复原值后也及时更新。不改正式账号。

5. 切后台再恢复、快切页面、较大系统/微信字体：不遗留等待动画、不闪回旧页面结果、不裁切。退出并重新登录同一隔离账号，资料和记录正常加载。
