## 动效实现与边界

- 使用小程序本地节点测量 + CSS 高度/透明度过渡，350ms、ease-in-out；不引入网页 Motion/Radix 包。
- 每次展开读取一次本地布局，收起不请求接口；不按动画帧执行 JavaScript。
- 快速点击覆盖旧测量结果，不排队播放；页面隐藏停止过渡，回来保持开合选择并重新测量。
- 内容更新和窗口尺寸变化仅重新测量已打开卡片；拖动滚动与触摸取消不误开合。
- 节点测量失败或 250ms 未回调，降级为完整静态内容，避免信息被锁住或裁切。该兜底不是常态动画效果。
- 页面离开清理测量定时器、监听器并忽略迟到结果。
