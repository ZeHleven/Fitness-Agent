## 实现

- 将“训练记录、饮食记录、体重记录”等复合名词中的“记录”从旧的一致性校验动词证据中排除。不是将整句强制判成查询，也不是绕过模型；其他真实修改指令继续保留。保留“把训练记录下来”“将饮食记录为…”等动词补语；模型不可用仍安全失败。原始语句和带“只给说明，不修改任何数据”的完整语句均覆盖。
- 通用提案详情改为页内二次确认，不依赖 showModal 或 showToast。勾选核对、点击确认/拒绝只打开黄色确认区；再次明确接受才请求服务端。取消、离页、过期、版本/指纹变化和旧点击回调均不能提交。
- 使用同步交互锁、防迟到读取序号和确认目标快照。明确提交后的网络失败先 GET 核对结果，不自动重发写操作；核对失败保留内容和错误、禁止继续提交，直到手动刷新并重新核对。沿用通用决策服务的请求标识/幂等机制。
- 成功响应先更新服务端权威状态，不因原生成功提示或刷新失败而误报失败。隐藏期间不取消已明确授权的后台请求，返回后只核对状态；旧提案响应不能写入另一详情页。
- 食品行隐藏内部 id/来源/版本字段，保留食品名称、份量和营养，包括显式零值。不改变提案原始 payload 或确认内容的服务端指纹。
- 新增通用提案真实页面行为测试，并加入 `test:proposal-contract`，后续标准 CI 会执行。
